Table Schemas

Sistem Informasi Kantor Lurah Maharatu — Database Structure

Keterangan:

PK = Primary Key
FK = Foreign Key
Tabel 1
users
Menyimpan data profil pengguna yang terdaftar di sistem. Tabel ini ter-link dengan Supabase Auth (auth.users) melalui kolom id. Data pengguna otomatis dibuat saat user melakukan registrasi.
Nama Field Tipe Data Keterangan
id (PK, FK) uuid Primary key, referensi ke auth.users(id). ON DELETE CASCADE.
name text Nama lengkap pengguna.
birth_date date Tanggal lahir pengguna.
email text Alamat email pengguna (unik).
created_at timestamptz Waktu pembuatan record. Default: now()
updated_at timestamptz Waktu update terakhir. Otomatis diperbarui via trigger.
Tabel 2
pengaduan
Menyimpan data pengaduan masyarakat. Pengguna dapat mengajukan keluhan atau aspirasi yang akan ditinjau oleh admin kelurahan. Status pengaduan dapat berupa: menunggu, diproses, selesai, atau ditolak.
Nama Field Tipe Data Keterangan
id (PK) uuid Primary key. Default: uuid_generate_v4()
user_id (FK) uuid Referensi ke users(id). ON DELETE SET NULL.
name text Nama pelapor.
nik text Nomor Induk Kependudukan (NIK) pelapor.
date date Tanggal pengaduan. Default: current_date
address text Alamat lengkap pelapor.
description text Isi/deskripsi pengaduan.
attachment_url text URL lampiran gambar (opsional). Upload via Cloudinary.
status text Status pengaduan. Nilai: menunggu | diproses | selesai | ditolak. Default: menunggu
admin_note text Catatan/tanggapan dari admin (opsional).
created_at timestamptz Waktu pembuatan record. Default: now()
updated_at timestamptz Waktu update terakhir. Otomatis diperbarui via trigger.
Tabel 3
pelayanan
Menyimpan data permohonan pelayanan administrasi. Mendukung 10 jenis surat: SKPW, SKBMR, Surat Kematian, SKTM, Surat Nikah, Ahli Waris, Domisili Usaha, Surat Penghasilan, Rekomendasi Usaha, dan Surat Domisili.
Nama Field Tipe Data Keterangan
id (PK) uuid Primary key. Default: uuid_generate_v4()
user_id (FK) uuid Referensi ke users(id). ON DELETE SET NULL.
jenis_pelayanan text Jenis pelayanan. Nilai: skpw | skbmr | kematian | sktm | nikah | ahli_waris | domisili_usaha | penghasilan | rekomendasi_usaha | domisili
name text Nama pemohon.
nik text Nomor Induk Kependudukan (NIK) pemohon.
phone text Nomor telepon/WhatsApp pemohon (opsional).
address text Alamat lengkap pemohon (opsional).
documents jsonb Array JSON berisi URL dokumen pendukung (KTP, KK, dll). Upload via Cloudinary. Default: []
status text Status permohonan. Nilai: menunggu | diproses | selesai | ditolak. Default: menunggu
admin_note text Catatan/tanggapan dari admin (opsional).
created_at timestamptz Waktu pembuatan record. Default: now()
updated_at timestamptz Waktu update terakhir. Otomatis diperbarui via trigger.
